# Trees Aboba

Аддон совместимости **Tree Physics** ↔ **Tan's Huge Trees** для Minecraft 1.21.1 (NeoForge).

- Небольшие деревья Tan's Huge Trees (ствол в один блок) падают от Tree Physics, как ванильные.
- Большие деревья (ствол толще) не падают.

## Как это работает

Tree Physics считает деревом только то, под стволом которого лежит корнистая земля (rooted dirt) —
он сам ставит её под ванильные деревья при генерации. Tan's Huge Trees строит деревья своим генератором,
поэтому метки нет и деревья не падают.

Аддон:

1. После того как Tan's Huge Trees поставил дерево в чанк, смотрит на форму дерева. Если ствол
   тонкий (типичный слой ствола ≤ `max_trunk_width`²), под подземную часть дерева ставится один блок
   корнистой земли. Под большие деревья — ничего, поэтому они остаются стоять.
2. Учит Tree Physics забирать листву Tan's Huge Trees: она `persistent` и без нормального значения
   `distance`, поэтому раньше падали бы только листья, касающиеся древесины.
3. Объединяет бревно / древесину / обтёсанные варианты в один тип, чтобы ствол из `*_wood` и
   сердцевина из `stripped_*_wood` считались одним деревом.

Работает только в **новых** чанках (метка ставится при генерации).

## Настройки

`config/trees_aboba-common.toml`

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | Включает метку для маленьких деревьев |
| `max_trunk_width` | `1` | Самый толстый ствол (в блоках), который ещё считается маленьким |
| `persistent_leaf_reach` | `8` | На сколько шагов от древесины забирается persistent-листва при падении |

## Сборка

`./gradlew build` — jar появится в `build/libs/`. GitHub Actions собирает автоматически.
